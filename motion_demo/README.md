# Signal Path

The [14-second motion film](support-workflow-demo.mp4) follows a fictional VPN support request through intake, triage, approved guidance, iterative review, independent verification, human approval, and a separate Jira publication step.

The square MP4 is 1440 × 1440 at 60 frames per second, with H.264 video and stereo AAC audio. The composition was written in code with OpenMotion using its Decision Tree template.

Download the [editable OpenMotion source project](Signal-Path-OpenMotion-English.zip). It contains the English titles, node illustrations, fonts, and OpenMotion drawing code. The video’s user-supplied music track is not redistributed in the source archive; provide your own audio when adapting the project.

The application’s front-end visual direction was guided by the Impeccable design plugin. The film is a motion-design illustration of the intended workflow, not a screen recording of the current application.
