# Code-generated workflow video

Run `python motion_demo/render.py` from the repository root to create `motion_demo/support-workflow-demo.mp4` (30 seconds, 1280×720, H.264/AAC). The renderer uses Pillow and imageio-ffmpeg if they are already available; it downloads no assets and makes no model or network calls.

The animation uses synthetic ticket text and generic integration labels. It illustrates the intended sequence: ticket intake, approved guidance, architect/critic revision, independent verification, specialist review, human approval, a separate publish action, and the integration boundaries.
