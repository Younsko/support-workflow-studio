# Signal Path

The [14-second workflow film](support-workflow-demo.mp4?raw=true) follows a fictional VPN ticket through intake, routing, evidence retrieval, plan revision, independent checks, human approval, and a separate Jira publish action. The public README also includes a streaming player.

The square MP4 is 1440 × 1440 at 60 frames per second, with H.264 picture and stereo AAC sound. The visuals use a code-driven OpenMotion composition. The soundtrack combines an excerpt of **« Базовый минимум » by SABI** with original interface sound effects.

The earlier procedural animation study remains available in [render.py](render.py). Running it writes `motion_demo/motion-study.mp4`.
